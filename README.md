# Stillwater · Tide Line

Coded prototypes for the Tide Line packaging pitch project.

- **Flow 1 · Pin to project**: open `flow-1/flow-1-prototype.html` in a browser.
- **Flow 2 · Board to client deck**: open `flow-2/flow-2-prototype.html` in a browser. The flow goes from the client board through references, themes, deck template, editor and pre-share check, then preview and share, client review and approval. It ends with the deck filed in Client projects.

Each prototype is a single self-contained HTML file. Use the controls bar to switch between Desktop and Mobile, jump to any designed screen (D1–D9, M1–M9), show hotspots or restart.

`flow-2/assets/` holds the hi-fi screens, wireframes and the 30 reference photos used in the prototype.
